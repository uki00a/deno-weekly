Denoの直近の開発について#

// deno-doc-ignoreコメント#

まだリリースはされていませんが、特定のコードに対するdeno doc --lintによる報告の無効化がサポートされています。

  • feat: support // deno-doc-ignore lint directives (denoland/deno_doc#829)

// deno-doc-ignoreコメントを記述すると、その次のコードに対するdeno doc --lintによる違反の報告が無効化されます。// deno-lint-ignoreと同様に、無視する違反種別の指定やコメントの記述などもサポートされています。

// deno-doc-ignore missing-explicit-type missing-jsdoc -- TODO: Write a JSDoc comment. 
export const foo = 123;

また、// deno-doc-ignore-fileによってファイル全体に対する違反報告の無効化もサポートされています。

deno desktop - メニュー項目におけるチェックマーク/アイコン/ツールチップのサポート#

まだマージはされていませんが、deno desktopのメニュー項目においてチェックマークやアイコン、ツールチップの表示をサポートする対応が行われています。

  • feat(desktop): support checked, icon, and tooltip on menu items (#36649)

Deno.MenuItemに以下の3つのプロパティーが追加されています。

  • checked
  • icon
  • tooltip

denext#

denext というNext.js互換なWebフレームワークが公開されています。

  • https://github.com/Brainwires/denext

App Routerやファイルシステムベースルーティングなどの各種機能に加え、deno lintプラグインなどが提供されているようです。

大きな特徴としてランタイムにおいてnpmパッケージへ依存しないことが意識されているようで、React及びReact DOMは使用せず、代わりにdenext本体から互換APIが提供されています。 それによって、ランタイムが@std以外のサードパーティコードへ依存せず、軽量化やサプライチェーン攻撃へのリスク軽減などが実現されているようです。
