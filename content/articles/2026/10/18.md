## Deno is joining Cloudflare (part 2)

[先週]({{< ref "articles/2026/10/11.md" >}})に引き続き、Deno の Cloudflare へのジョインに関して新しい情報が公開されています。

### The state of Deno after the Cloudflare announcement

`denoland/deno` リポジトリの Issue で改めて今後の方針についてアナウンスされています:

- [The state of Deno after the Cloudflare announcement (#37030)](https://github.com/denoland/deno/issues/37030)

2.9 LTS バージョンについては、2027/10 まで毎月リリースされる予定とのことです。脆弱性への対応も引き続き実施予定とのことです。

ただし、バグ修正に関する PR はマージされるものの、新機能の追加に関する PR については今後はマージされることはないとのことです。

### Supabase

Supabase からもアナウンスが行なわれています:

- https://x.com/supabase/status/2109630227085168640

Edge Functions は現在は Deno Deploy をベースとしているわけではないとのことです。そのため、Deno Deploy の終了による影響を直ちに受けるわけではなさそうです。

また、現在開発中の [Compute](https://supabase.com/compute) においては、Deno に加えて Node.js と Bun もサポートが予定されているようです。

### Deno Goes the Way of the Dinosaur

Socket.dev からもまとめ記事が公開されています:

- [Deno Goes the Way of the Dinosaur](https://socket.dev/blog/deno-acquisition)

Deno の Cloudflare へのジョインに関するまとめに加えて、[Ende](https://github.com/theende/ende) や [Dodo](https://github.com/are-we-dodo-yet/dodo) などのコミュニティによる Deno のフォークも紹介されています。
