## Denoの直近の変更

### `// deno-doc-ignore`コメント

特定のコードに対する[`deno doc --lint`]({{< ref "articles/deno/v1.38.md" >}})による報告の無効化がサポートされています。

- [feat: support `// deno-doc-ignore` lint directives (denoland/deno_doc#829)](https://github.com/denoland/deno_doc/pull/829)

`// deno-doc-ignore`コメントを記述すると、その次のコードに対する`deno doc --lint`による違反の報告が無効化されます。`// deno-lint-ignore`と同様に、無視する違反種別の指定やコメントの記述などもサポートされています。

```typescript
// deno-lint-ignore missing-explicit-type missing-jsdoc -- TODO: Write a JSDoc comment. 
export const foo = 123;
```

また、`// deno-doc-ignore-file`によってファイル全体に対する違反報告の無効化もサポートされています。

## denext

**denext** というNext.js互換なWebフレームワークが公開されています。

- [https://github.com/Brainwires/denext](https://github.com/Brainwires/denext)

App Routerやファイルシステムベースルーティングなどの各種機能に加え、`deno lint`プラグインなどが提供されているようです。

大きな特徴としてランタイムにおいてnpmパッケージへ依存しないことが意識されているようで、React及びReact DOMは使用せず、代わりにdenext本体から互換APIが提供されています。
それによって、ランタイムが[@std](https://github.com/denoland/std)以外のサードパーティコードへ依存せず、軽量化やサプライチェーン攻撃へのリスク軽減などが実現されているようです。
