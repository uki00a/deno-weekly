## dax 0.50.0

[dax 0.50.0](https://github.com/dsherret/dax/releases/tag/0.50.0)がリリースされています。

コマンドの引数に対する`CommandBuilder`の指定がサポートされています ([dsherret/shell#34](https://github.com/dsherret/shell/pull/34)):

```typescript
import { $ } from "@david/dax";

await $`echo foo ${$`echo bar`}`;
// Output: foo bar
```

また、`ProcessTracker`という、daxによって実行されたプロセスを監視するための新規APIも追加されています ([dsherret/shell#26](https://github.com/dsherret/shell/pull/26))。
